# 社員意見箱

就業規則や業務・勤務についての意見を匿名で投稿し、社員が賛成／反対で投票できる社内ツールです。
画面は GitHub Pages、データは Google スプレッドシート（Apps Script）に保存します。

## できること

| 利用者 | できること |
|---|---|
| 社員 | アカウント登録（メールアドレス＋パスワード）、意見の投稿（匿名）、賛成・反対の投票（1人1票）、コメント（匿名）、未投票の意見の確認、パスワード変更 |
| 運営 | 投票期限の変更、意見書として提出（PDF出力）、見送り、未投票者の確認、不適切な投稿の非表示、実施済の登録、アカウントの削除・仮パスワード発行 |
| 会社 | 提出された意見の閲覧、可決／一部可決／否決／継続検討と理由・実施予定日の入力 |

- 投票中の意見は **賛成の多い順** に並びます。
- 意見の流れ：`投票中` →（期限到来）→ `締切・提出待ち` →（運営が提出）→ `提出済` →（会社が回答）→ `回答済` → `実施済`
- 意見書は、ブラウザの印刷画面から「PDFに保存」を選ぶと PDF になります。

## アカウントについて

- 社員は画面の「はじめての方：アカウント登録」から、**氏名・部署・メールアドレス・パスワード**を登録します。運営の承認は不要で、登録するとすぐ使えます。
- **同じ氏名がすでに登録されている場合は登録できません**（1人1アカウントにするため）。全角・半角や空白の有無の違いは同じ氏名とみなします（「佐野 太郎」と「佐野太郎」は同一）。
- 同じメールアドレスでの重複登録もできません。
- パスワードは照合用のハッシュ値だけを保存します。端末に保存されるのはパスワードではなく、ログイン状態を表す文字列（90日間有効）です。
- パスワードを忘れた人には、運営が「運営」タブから **仮パスワード** を発行して本人に伝えます。本人はログイン後、右上の ⚙ から変更します。
- 退職・重複・なりすましなどのアカウントは、運営が「運営」タブから **削除** できます。削除すると投票率の分母からも外れます。
- 同姓同名の社員がいる場合は、あとから登録する人が氏名に区別を付けて登録してください（例：「佐野 太郎（技術部）」）。

## 匿名性について

- 意見・コメントには **投稿者を記録しません**。
- 「投票済ログ」シートには **誰が・どの意見に・何日に投票したか** だけを記録し、賛成か反対かは記録しません。
- 賛成・反対の数は、投票期間中はスクリプト内部（スクリプトのプロパティ）に保存し、**締切後にだけ「意見」シートに書き出します**。
  スプレッドシートの変更履歴から「このログの行と同時に賛成が1増えた」と突き合わせられないようにするためです。
- 未投票者の一覧は運営だけが見られます。会社には投票率だけを表示します。
- スプレッドシートの持ち主（運営）は、社員名簿と投票済ログを見られます。スプレッドシートの共有は運営担当だけにしてください。

## 同時に操作しても大丈夫な理由

- 画面からは「意見12に賛成」のような **操作だけ** を送り、全データの上書きはしません。
- Apps Script 側で LockService を使い、書き込みを **1件ずつ順番に** 処理します。同時に押されても票は消えません。

# セットアップ手順

## 1. スプレッドシートを作る

1. Google ドライブで新しいスプレッドシートを作成します（例：`社員意見箱`）。
2. メニュー「拡張機能」→「Apps Script」を開きます。
3. 最初から入っている `コード.gs` の中身をすべて消し、[`gas/Code.gs`](./gas/Code.gs) の内容を貼り付けて保存（💾）します。
4. スプレッドシートのタブに戻って再読み込みすると、メニューに「意見箱」が出ます。
5. 「意見箱」→「初期設定（シートを作成）」を実行します。
   - 初回は Google の承認画面が出ます。「続行」→ 自分のアカウント →「詳細」→「（安全ではないページ）に移動」→「許可」と進めてください（自分で作ったスクリプトのため問題ありません）。

## 2. 運営・会社用のパスワードを設定する

- 「意見箱」→「運営パスワードを設定」
- 「意見箱」→「会社用パスワードを設定」

それぞれ6文字以上。スプレッドシート上には表示されず、照合用のハッシュ値だけが保存されます。

## 3. ウェブアプリとしてデプロイする

1. Apps Script の画面右上「デプロイ」→「新しいデプロイ」。
2. 「種類の選択」の歯車 →「ウェブアプリ」。
3. 次のように設定して「デプロイ」。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をコピーします。

## 4. 画面を公開する（GitHub Pages）

1. `index.html` の `const API_URL = "…";` に、3 の URL を貼り付けてコミットします（現在は組み込み済み。デプロイし直して URL が変わった場合のみ変更）。
   （空のままでも、初回起動時の「接続先の設定」画面で URL を入れれば、その端末だけで使えます）
2. GitHub のリポジトリ「Settings」→「Pages」→ Branch を `main` / `/ (root)` にして「Save」。
3. 数分後に表示される URL（`https://tvss2p.github.io/ikenbako/`）を社員に案内し、各自アカウント登録してもらいます。

## 5. 設定を変える

「設定」シートで変更できます。

| 項目 | 初期値 | 内容 |
|---|---|---|
| 投票期間（日） | 14 | 投稿日から何日後を投票期限にするか |
| 回答期限（日） | 30 | 提出日から何日後を会社の回答期限にするか |
| 提出先 | 佐野ケーブルテレビ 御中 | 意見書の宛先 |
| 提出者名義 | 社員意見箱 運営 | 意見書の提出者欄 |

## 注意事項

- 各シートの **列の順番や見出しは変えないでください**。
- 「社員名簿」の在籍を `×` にすると、その人はログインできなくなり、投票率の分母からも外れます（削除せずに一時的に止めたい場合）。
- 旧版（投票コード方式）の「社員名簿」があった場合は、自動で「社員名簿（旧）」に名前が変わり、新しい「社員名簿」が作られます。旧シートは削除して構いません。
- 投票は1人1回で、取り消しはできません。
- ログインに10回続けて失敗すると、そのアカウントは10分間ログインできなくなります。
- `Code.gs` を修正した場合は「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン：新バージョン」→「デプロイ」で更新します（URL は変わりません）。
- ここで出力する「意見書」は社内の提案書です。就業規則の変更時に労働基準法第90条で必要となる「過半数代表者の意見書」とは別のものです。
